# 江西省县域社会结构、社会保障与制度分配｜2025阶段性实证研究包

**核验日期：2026-10-27**  
**研究层级：江西省、11个设区市、100个县级行政区（2024年代码参考映射，2025末官方终码表待核）**  
**性质：第一阶段已完成的可复核研究成果，并非全省100县所有指标采集完成或因果研究的最终稿。**

## 核心发现与严格证据边界

- **峡江2025**：机关事业单位占三类年末待遇领取人数 **6.095%**，三类年度发放额占比 **30.202%**；用年度金额/年末人数/12估算的月金额约5,389元，企业约2,186元，居民约241元。数据来源为署名统计局公报的**第三方全文转载，B级、尚未取得县政府原文**。不得称其为2025年江西全省分配份额。年度金额与年末人数不同统计时点，不是真实月均养老金。
- **峡江2024→2025**：三类年度发放额从48,140.38万元升至53,700.58万元；使用对称精确恒等式将金额增长拆分为领取人数变化分量与人均金额代理变化分量。分解**不是制度或政策的因果效应**。
- **赣州2024→2025**：18个行政建制县区两年常住人口数据直接依据政府公报，11县减少、6县增加、1县持平，18县城镇化率全部提高。各年份市级合计包含功能区，因此不能用18县之和假设等于整市合计。
- **人口变动**：峡江2025年常住人口变动 -3,465人，出生-死亡 -117人，差值-3,348人；江西全省总变动-28万人、自然变动约-8.9万人，差值约-19.1万人。差值可能含统计修订，**不等于直接观测的净迁出人数**。
- **财政**：全省社保基金**执行**和省级社保基金**决算**具有不同范围及状态，亦不等于“单项养老金”支出。县一般公共预算社会保障和就业支出不能与三类养老金金额直接相减。

## 复现步骤

使用 Python 3.11+；`prepare_data.py`、`reproduce.py`、`test_research.py`以标准库为基础，图表需要 `matplotlib`，Excel导出需要 `artifact_tool`，PDF需要 `reportlab`。

在本目录执行：

```bash
python scripts/prepare_data.py
python scripts/reproduce.py
python scripts/test_research.py
python scripts/build_workbook.py
python scripts/make_report.py
```

注意：`prepare_data.py`中的观测数值为查阅政府公报及注明转载资料后**人工转录、显式保留来源ID**的证据记录，不是自动实时抓取的政府API。脚本能复算结论但不能独立证明原始来源的真实性。原始HTML/PDF网页快照及SHA-256尚未保存，来源URL和具体定位保存在`sources.csv`。

## 审计与比较原则

1. `A` = 可直接访问的政府/主管机关原始发布（未必保存本地网页）；`B` = 署名原文转载/无法最终核实官网原件。**网页URL与人工记录不等于本地完整证据快照。**
2. 各县级养老金份额的分母仅为县公告所列三类养老待遇年度发放金额之和，并非包含所有补充年金的退休总收入。
3. 年末领取人数与全年金额形成的“月均代理”只能做带限制比较；另需养老经办真实人月数据。
4. 省、市、县和功能区、基金预算与一般公共预算、执行与决算不得交叉代替。
5. 公积金实缴缴存额按人数折算不是个人工资；市级数据不可按人口硬分摊至县级。
6. 仅2/100县三类发放金额完整，1/100县人数也完整：**不进行省级养老金份额推断或基于极小养老金样本的回归。**
7. 本研究目前是描述性与算术结构分解，不声称已识别政策改革的因果效应或存在任何确定的财政违法行为。
