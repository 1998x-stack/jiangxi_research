# 县级养老保险数据补证——依法公开汇总数据请求模板

> 本文件仅是**研究文本模板**。尚未提交政府信息公开申请、未取得新的行政机关答复。不得在论文或README中暗示已经获得经办机构原始数据。

## 研究目的与所需范围

申请获取江西省某一县（市、区）2024—2025年社会保险三类制度的**已经存在的公开或可公开统计汇总数据**，用于人口与保障制度研究。

**申请内容（请按机关现有统计报表提供）**

1. 企业职工基本养老保险、机关事业单位基本养老保险、城乡居民基本养老保险，按2024年及2025年各月分别列示：**实际待遇领取人数**、按月发放基本养老金金额、年度补发额及补发所涉年月。
2. 企业职工基本养老保险与机关事业单位基本养老保险是否包含企业年金、职业年金、统筹外待遇、离休费、丧葬抚恤等项目；若属于分别统计，提供既有统计口径或指标解释。
3. 城乡居民2025年基础养老金分月**实际执行**最低标准、县额外加发的生效时间、回溯补发时间，以及依法可公开的县级财政实际补贴拨付汇总。
4. 如县级不经办或不掌握企业养老基金某一事项，说明适当的上级管理/经办机关或现有公开表所在位置。
5. 对社保基金预算和决算：按现行财政会计科目、险种、财政补贴收入、基金待遇支出、上解下拨、结余区分；注明是**预算数、执行数还是决算数**。

只需要汇总、非识别性统计记录；**不请求或接收任何参保个人的姓名、身份证、账号、具体缴费和家庭信息**。

如现有报表对某些问题没有数据，明确答复“不存在该项统计记录”或提供其他适用表格即可。研究团队不会要求行政机关为本申请额外计算个体微观数据。

## 补证工作台账

使用`python scripts/build_official_collection_queue.py`生成`outputs/county_primary_evidence_request_queue_2025.csv`。

**研究记录状态要求**：起始状态必须`NOT_SUBMITTED`、`NOT_RECEIVED`，仅在实际提交和收到政府反馈且保存凭证后才能修改。成功响应也需区分官方信息公开答复与其他转载材料。

**核心限制**：没有统计公开数据不代表政府没发养老金；统筹层级可能导致县级不单列企业职工养老金基金。申请记录与经办答复必须分别保留时间、来源及准确口径。
