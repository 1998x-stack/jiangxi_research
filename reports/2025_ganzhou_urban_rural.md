# 赣州2024—2025年城乡常住人口变化：县域结构与口径边界

> **研究性质**：由赣州市2024、2025年分县常住人口及城镇化率重新计算的**派生估算**，不是政府发布的城镇人口原始人数，也不是观察到的迁移流量。更新于2026-10-27。

## 样本与证据

- 官方来源 **S05（2025）**：https://www.ganzhou.gov.cn/zfxxgk/tjzdtjfx/202605/1b10c9c94cf1443f851d6523be5863d3.shtml
- 官方来源 **S06（2024）**：https://www.ganzhou.gov.cn/zfxxgk/c100093n1/202503/c7bfdc7911ac4c898c559e58a215509a.shtml
- 只纳入18个行政县级单位。赣州经济技术开发区与蓉江新区是另列的功能区统计单元，**未纳入县级样本**；县区合计不能自动视作全市合计。
- 已对72个两年表格单元格进行自动比对，但统计口径的历史一致性及城乡分类边界仍需要核对。

## 可复算结果

| 指标 | 2024—2025变化（人） |
|---|---:|
| 18个县区常住人口总量 | **-11,000** |
| 18个县区估算城镇人口 | **+113,552.13** |
| 18个县区估算乡村人口 | **-124,552.13** |
| 算术闭合（城镇变化+乡村变化） | **-11,000** |

18县区均出现估算城镇人口增加、乡村人口减少；在公布精度的保守误差界内，这些变化的方向均保持不变。**但不能因此声称18县出现了等量的农村人口迁入县城**。城乡分类重划、跨县流动、出生死亡及人口抽样修订都可能参与解释。

## 计算定义

`urban_proxy = year_end_resident_population × published_urbanization_percentage / 100`

`rural_proxy = year_end_resident_population - urban_proxy`

采用 Python `decimal.Decimal` 避免数值运算误差；来源人口保留0.01万人（即100人），比率保留0.01个百分点。对每一县的城镇人数变化使用保守界：

`E_change <= (50 + (P_2024+50)×0.00005) + (50 + (P_2025+50)×0.00005)`。

该界估计公开表格四舍五入造成的误差，但不包含人口抽样误差、口径修订或城乡地域重分类，不能当作统计置信区间。

## 后续竞争性解释

1. **县域内部再集聚**：居民住所更多落在县城或镇区。
2. **跨地域迁移**：中心城区及功能区吸纳部分常住人口。
3. **统计重分类**：城乡划分编码发生变化，城镇化率提高但没有等量物理搬迁。
4. **人口自然变动结构**：城乡不同出生死亡率改变人口比重。

**独立证据**：2024—2025城乡地域分类代码；2020年普查镇村人口；迁移人口抽样资料；县域中小学及医疗服务资源变动。未取得以上数据前不作因果判断。
