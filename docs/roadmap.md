# 研究路线图与验收标准

**研究对象**：2025江西全省、11个设区市、100个县级行政区。2024直接比较；延长到2020—2025须满足同口径和原始证据条件。

## Phase 0 — 研究范围与原始资料索引（部分完成）

- [x] 建立100个县级单位的研究映射（基于2024代码参考）。
- [x] 建立16项来源索引及142条可复算观察；区分A级政府资料、B级转载与C级计算估算。
- [ ] 核对2025年末官方终版行政区划代码及历史边界变动。
- [x] 保存15/16个来源网页响应及SHA-256；赣州两年人口72个县级表格单元格已复核。
- [ ] 获取S08住建厅年报原件，并对65条仅数字定位观察完成上下文复核。

**验收**：所有核心结论能定位到政府原始表格；县区代码、日期、单位和人口口径无歧义。

## Phase 1 — 关键县养老金口径复核（进行中）

- [x] 峡江2024/25三类养老金年度金额及年末人数复算。
- [x] 吉安县2025三类养老金金额份额计算，明确人数缺口。
- [ ] 核实峡江、吉安政府公报原始全文和人社经办数据。
- [ ] 取得全年领取人月数，剥离可能补发或非基本养老金项目。

**验收**：以年度平均受益人月或公开的官方人均月待遇重算；拒绝拿年末人数计算“精确月均”。

## Phase 2 — 人口、就业、公积金（进行中）

- [x] 政府资料支持的赣州18县2024—2025常住人口比较。
- [ ] 延长2020—2023连续序列；识别人口变化与统计修订。
- [ ] 收集不同县养老实际缴费人数、年龄结构、就业/工资分层。
- [ ] 逐图复核江西11个设区市公积金原始统计附表；县级未披露维持缺失。

**验收**：逐项统计有效县数、缺失原因、可比性、城镇化和迁移概念边界。

## Phase 3 — 财政账目与制度史（未完成）

- [ ] 区分全省与省本级、预算执行与决算、养老险种与其他社保基金。
- [ ] 核验2014年机关事业养老保险改革、统筹制度与2025退休政策的适用规则。
- [ ] 以实际同险种基金收支和补贴记录，建立资金流向可核对模型。

**验收**：每个会计指标有预算科目、归集范围和本级/全省标签；严禁错误跨账相减。

## Phase 4 — 统计解释及公开研究论文（未完成）

- [ ] 建立竞争性假说与反例样本；审视选择偏差和生态谬误。
- [ ] 样本支持时进行描述回归及敏感性检验；仅有有效识别方案才作因果结论。
- [ ] 独立双人复录核心数字、随机抽查其他数据至少20%。
- [ ] 更新论文、源代码、工作簿、证据索引和审计报告。

**最终验收**：外部研究者能从数据和代码复现全部核心图表；每项结论明确事实/相关/机制/因果的证据等级与局限。
